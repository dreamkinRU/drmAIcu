# v.3.4.0 PATCHMASTER

## Система автопатчей
Полностью исключает ручное редактирование файлов.

### Как это работает
1. ИИ генерирует JSON-патч с полным содержимым файла
2. Ты сохраняешь его в папку `patch/`
3. Панель автоматически сканирует папку каждые 5 сек
4. Показывает статус: применен / ожидает / ошибка
5. Кнопка "Просмотр" делает dry-run с валидацией
6. Кнопка "Применить" делает атомарную замену с тройным бэкапом
7. Кнопка "Откатить" возвращает последнюю рабочую версию

### Безопасность
- Валидация синтаксиса до применения
- Атомарная запись через .tmp + os.replace()
- Тройной бэкап (обычный, verified, LATEST)
- Манифест всех применений
- Возможность отката в один клик

### Формат патча
```json
{
  "patch_id": "001",
  "target_file": "src/App.tsx",
  "description": "Добавлена кнопка X",
  "author": "Qwen",
  "created_at": "2026-11-14T20:00:00",
  "checksum": "sha256:abc...",
  "full_file_content": "полный код файла"
}
```
