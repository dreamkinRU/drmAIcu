# drmAIcu — История изменений

## v3.5.0 MULTI-ATOMIC (Текущая)
### Революция в надёжности
- **Мультифайловые патчи**: Возможность обновлять несколько файлов одним патчем через массив `operations`.
- **Двухфазный атомарный коммит**: 
  1. Фаза валидации: проверка всех файлов перед любой записью.
  2. Фаза записи: создание бэкапов, запись, проверка SHA-256. При любой ошибке — полный откат всех файлов.
- **Железобетонный движок unified_diff**: Поиск по текстовому контексту, а не по номерам строк. Защита от дублирования кода и fuzzy-допуск для съехавших проб.
- **Умная очистка проекта**: Эвристический анализатор, помечающий пустые файлы, кэш, дубликаты и устаревшие версии (`_v3`, `_fixed`, `_ru`) с рекомендациями к удалению.
- **Перезапуск из панели**: Кнопка в шапке, корректно убивающая процессы и перезапускающая систему через watchdog-лаунчер.

## v3.4.2 CONTEXT-DIFF
- Переписан движок `apply_diff`: теперь он ищет уникальное совпадение контекста, предотвращая вставку кода не туда.
- Идемпотентность: повторное применение патча не создаст дубликатов.

## v3.4.1 CLEANUP-FIXED
- Исправлена логика анализатора очистки: теперь правила (например, поиск `_v3.0.4.py`) работают во всех подпапках (`public/`, `docs/`), а не только в корне.
