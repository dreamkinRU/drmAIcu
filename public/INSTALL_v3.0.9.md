## 🚀 Быстрый старт

### Вариант 1: Только Ollama (локально)

1. Установи Ollama: https://ollama.ai
2. Запусти Ollama:
   ```bash
   ollama serve
   ```
3. Скачай модели:
   ```bash
   ollama pull qwen2.5-coder:1.5b
   ollama pull qwen2.5-coder:14b
   ```
4. Открой React-дашборд в браузере
5. Выбери режим **"🏠 Только Ollama"**
6. Убедись что URL: `http://localhost:11434`
7. Отправь запрос!

### Вариант 2: Только Groq (облако)

1. Получи API ключ: https://console.groq.com/keys
2. Открой React-дашборд в браузере
3. Выбери режим **"☁️ Только Groq"**
4. Введи Groq API ключ
5. Отправь запрос!

### Вариант 3: Все модели (Ollama + Groq)

1. Запусти Ollama: `ollama serve`
2. Получи Groq API ключ
3. Выбери режим **"⚡ Все (Ollama + Groq)"**
4. Введи оба: URL Ollama + Groq API ключ
5. Отправь запрос — 5 моделей ответят параллельно!

## 📊 Режимы работы

### 🏠 Только Ollama
- **Модели**: Qwen 2.5 Coder 1.5B, Qwen 2.5 Coder 14B
- **Плюсы**: Работает без интернета, бесплатно, приватно
- **Минусы**: Требует установки Ollama, медленнее

### ☁️ Только Groq
- **Модели**: Llama 3.1 8B, Llama 3.1 70B, Mixtral 8x7B
- **Плюсы**: Быстро, мощные модели, не требует установки
- **Минусы**: Нужен интернет, бесплатный лимит

### ⚡ Все (Ollama + Groq)
- **Модели**: 5 моделей одновременно
- **Плюсы**: Максимальный выбор, арбитр выбирает лучшее
- **Минусы**: Требует и Ollama, и Groq API ключ

## 🎯 Как использовать

### 1. Открой дашборд
Открой `http://localhost:5173` в браузере

### 2. Перейди во вкладку "▶ Консоль"
Это главная вкладка для работы с моделями

### 3. Выбери режим
Нажми одну из трёх кнопок:
- 🏠 Только Ollama
- ☁️ Только Groq
- ⚡ Все (Ollama + Groq)

### 4. Настрой провайдеры
- Для Ollama: проверь URL (по умолчанию `http://localhost:11434`)
- Для Groq: введи API ключ

### 5. Отправь запрос
Напиши задачу в поле "Запрос" и нажми "▶ Отправить"

### 6. Смотри результаты
- Все ответы моделей отображаются в списке
- Арбитр выбирает лучший ответ
- Обоснование выбора показывается ниже

### 7. Копируй код
Нажми "📋 Копировать код" чтобы скопировать лучший ответ

## 🔧 Решение проблем

### Ollama не отвечает
```bash
# Проверь что Ollama запущен
ollama serve

# Проверь что модели скачаны
ollama list

# Скачай модели если нужно
ollama pull qwen2.5-coder:1.5b
ollama pull qwen2.5-coder:14b
```

### Groq API ошибка
- Проверь что API ключ правильный
- Проверь что не превышен лимит (бесплатный: 30 запросов/мин)
- Получи новый ключ: https://console.groq.com/keys

### CORS ошибка для Ollama
Ollama по умолчанию поддерживает CORS. Если ошибка:
```bash
# Запусти Ollama с разрешением CORS
OLLAMA_ORIGINS=* ollama serve
```

### Порт 5173 занят
```bash
# Запусти на другом порту
npm run dev -- --port 3000
```

## 🎨 Интерфейс
