## 🚀 Как использовать

### Запуск React-дашборда
```bash
cd G:\Mega\git\drmAIcu
npm run dev
```

Откроется: **http://localhost:5173**

### Навигация
1. Используйте **панель статистики** для быстрого перехода в нужную вкладку
2. Наведите мышь на **вкладку** для просмотра подсказки
3. Наведите мышь на **блок статистики** для просмотра подробной информации
4. Наведите мышь на **цветную точку статуса** провайдера для просмотра статуса

### Управление Ollama
1. Перейдите во вкладку "Провайдеры"
2. Используйте кнопки управления Ollama:
   - ▶ **Запуск** — запустить Ollama
   - 🔄 **Перезапуск** — перезапустить Ollama
   - ⏸ **Остановка** — остановить Ollama
3. Следите за логами во вкладке "Логи"

### Редактирование документации
1. Перейдите во вкладку "MD"
2. Выберите файл из списка блоков
3. Отредактируйте содержимое в редакторе
4. Нажмите "💾 Сохранить"

### Исправление ошибок
1. Перейдите во вкладку "Анализ кода"
2. Нажмите "🔧 Исправить" для конкретной ошибки
3. Или "🔧 Исправить все" для массового исправления
4. Разверните блок "📋 Лог исправления" для просмотра подробностей
