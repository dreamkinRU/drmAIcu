# drmAIcu v3.2.0 — Новые функции и исправления

## 🎯 Обзор обновления

Версия v3.2.0 — масштабное обновление с фокусом на управление агентами, мониторинг провайдеров и улучшение пользовательского интерфейса.

---

## ✨ Новые функции

### 1. Управление агентами

#### Что добавлено
- **Включение/выключение агентов** — кнопки для каждого агента
- **Подробные описания** — для каждого агента добавлено описание его функций
- **Магазин агентов** — импорт готовых агентов (ML, Web, DevOps, Security, Mobile)
- **Мониторинг прогресса** — визуализация выполнения задач

#### Как использовать
1. Откройте вкладку "🤖 Агенты"
2. Нажмите "▶ Включить" или "⏸ Выключить" для управления агентом
3. Читайте описания для понимания функций каждого агента
4. Нажмите "🛒 Магазин агентов" для импорта новых агентов

#### Пример
```
Агент №1 — Развитие системы
Статус: АКТИВЕН
Стек: Java, Python, VBA/Excel
Задача: Исправление ошибок компиляции и импорта модулей
Описание: Основной агент для развития инфраструктуры drmAIcu...
```

---

### 2. Улучшенные провайдеры LLM

#### Что добавлено
- **Реальная проверка Ollama** — автоматическая проверка статуса каждые 5 секунд
- **Кнопки управления Ollama** — запуск, остановка, перезапуск
- **Мониторинг RAM/VRAM** — отображение используемой памяти с онлайн-обновлением
- **Фильтрация провайдеров** — все/онлайн/оффлайн
- **Настройки API ключей** — для каждого облачного провайдера
- **Подробная информация** — описания, ссылки, статистика

#### Как использовать
1. Откройте вкладку "🌐 Провайдеры"
2. Проверьте статус Ollama (автоматическая проверка)
3. Используйте кнопки управления Ollama (запуск/остановка/перезапуск)
4. Следите за RAM/VRAM (обновление каждые 5 сек)
5. Включайте/выключайте провайдеры кнопками "✅ Вкл" / "❌ Выкл"
6. Настраивайте API ключи для облачных сервисов
7. Фильтруйте по статусу (все/онлайн/оффлайн)

#### Пример мониторинга
```
🏠 Ollama (Локально)
Статус: ✅ Онлайн • RAM: 2048MB • VRAM: 1024MB
URL: http://localhost:11434
[▶ Запуск] [🔄 Перезапуск] [⏸ Остановка]
```

### 3. MD-редактор с AI

#### Что добавлено
- **Переименована вкладка** — "Документация" → "MD"
- **Редактор Markdown** — с подсветкой синтаксиса
- **AI-подсказки** — автоматические предложения по улучшению
- **Двухпанельный интерфейс** — редактор + подсказки рядом
- **Чтение/запись файлов** — интеграция с файловой системой

#### Как использовать
1. Откройте вкладку "📝 MD"
2. Введите имя файла в поле "Имя файла"
3. Напишите или отредактируйте Markdown документ
4. Нажмите "✨ Получить подсказки" для AI-анализа
5. Изучите предложения по улучшению
6. Внесите изменения в документ
7. Нажмите "💾 Сохранить" для сохранения файла

#### Пример
```markdown
# drmAIcu v3.2.0

## Описание
Система управления AI-агентами

## Возможности
- Управление агентами
- Мониторинг провайдеров
- MD-редактор с AI
```

### 4. Анализ кода с исправлением

#### Что добавлено
- **Обнаружение ошибок** — автоматический анализ кода
- **Классификация** — критические, предупреждения, рекомендации
- **Исправление через AI-Guardian** — кнопка "Исправить" для каждой ошибки
- **Массовое исправление** — кнопка "Исправить все"
- **Отслеживание статуса** — помеченные как исправленные

#### Как использовать
1. Откройте вкладку "⟨⟩ Анализ кода"
2. Просмотрите найденные проблемы
3. Классификация по серьёзности (critical/warning/info)
4. Нажмите "🔧 Исправить" для конкретной ошибки
5. Или "🔧 Исправить все" для массового исправления
6. Отслеживайте статус (исправлено/не исправлено)

#### Пример ошибки
```
🔴 CRITICAL | agent_engine.py:113
asyncio.get_event_loop() — deprecated

В Python 3.10+ get_event_loop() вызывает DeprecationWarning

Решение: Заменить на asyncio.get_running_loop()

Было: loop = asyncio.get_event_loop()
Стало: loop = asyncio.get_running_loop()
```

## 🔧 Исправления

### 1. Кодировка MD файла
- **Проблема**: MD файл отображался с искажёнными символами
- **Решение**: Убраны emoji из MD файлов, используется чистый текст

### 2. AI-Guardian для всех файлов
- **Проблема**: AI-Guardian работал только с agent_engine.py
- **Решение**: Расширен для поддержки всех файлов проекта (main.py, settings.json, launcher.bat, context_manager.py)

### 3. Проверка Ollama
- **Проблема**: Ollama показывался как "ОНЛАЙН" даже когда не был запущен
- **Решение**: Добавлена реальная проверка через API каждые 5 секунд

### 4. Порядок вкладок
- **Проблема**: Вкладка "Панель" была не в начале
- **Решение**: Изменён порядок: Консоль → Панель → Агенты → Провайдеры → MD → Анализ кода → Логи → Задачи

### 5. Информативный футер
- **Проблема**: Дублирование версии в футере
- **Решение**: Убран лишний текст, оставлена только полезная информация
