🔧 drmAIcu v3.0.3 FORTRESS

Универсальный экспорт/импорт контекста для работы с AI

📦 Что это?

context_manager.py — скрипт для экспорта всего состояния проекта в один JSON-файл. Этот файл ты передаёшь AI в следующем диалоге, и AI сразу понимает что делать — без объяснений.

📥 Шаг 1: Скачай context_manager.py

📥 Скачать context_manager.py

Помести файл в папку drmAIcu рядом с main.py

📤 Шаг 2: Экспорт контекста

1
Открой cmd в папке drmAIcu
2
Выполни команду:
python context_manager.py export
python context_manager.py export
3
Получишь файл context_export.json
Что экспортируется:
✓ main.py
✓ agent_engine.py
✓ settings.json
✓ launcher.bat
✓ context_manager.py
✓ Список файлов в backups/ и logs/
✓ Метаданные (Python версия, платформа, хеши)

📥 Шаг 3: Передай AI

1
Открой context_export.json в блокноте
2
Скопируй ВСЁ содержимое
3
Вставь в новый диалог с AI и напиши задачу
Пример сообщения AI:
"Вот контекст проекта drmAIcu v3.0.3. [вставь JSON]. Задача: исправить ошибку X в main.py"

🔄 Шаг 4: Импорт изменений от AI

Когда AI даст тебе исправленный код — он вернёт его в формате context_export.json. Импортируй так:

python context_manager.py import context_from_ai.json
python context_manager.py import context_from_ai.json
Что делает импорт:
✓ Создаёт бэкап текущих файлов в backup_before_import_*/
✓ Проверяет хеши файлов
✓ Восстанавливает файлы из контекста
✓ Показывает что изменилось

🛡️ Безопасность

  • Перед каждым импортом создаётся бэкап
  • Проверяются SHA256 хеши файлов
  • AI-Guardian в main.py работает параллельно для agent_engine.py
  • Если что-то пошло не так — восстанови из backup_before_import_*/
