## 🔧 Использование

### Консоль
1. Выберите режим: Ollama / Groq / Все
2. Для Ollama: проверьте URL (по умолчанию `http://localhost:11434`)
3. Для Groq: введите API ключ
4. Напишите запрос и нажмите "Отправить"
5. Смотрите ответы моделей и выбор арбитра

### Агенты
1. Включите/выключите агентов кнопками
2. Читайте описания для понимания функций
3. Откройте магазин для импорта новых агентов
4. Следите за прогрессом выполнения задач

### Провайдеры
1. Проверьте статус Ollama (автоматическая проверка)
2. Используйте кнопки управления Ollama
3. Следите за RAM/VRAM (обновление каждые 5 сек)
4. Включайте/выключайте провайдеры
5. Настраивайте API ключи для облачных сервисов
6. Фильтруйте по статусу (все/онлайн/оффлайн)

### MD-редактор
1. Откройте вкладку "MD"
2. Редактируйте Markdown документ
3. Нажмите "Получить подсказки" для AI-анализа
4. Сохраните файл с нужным именем

### Анализ кода
1. Просмотрите найденные проблемы
2. Классификация по серьёзности (critical/warning/info)
3. Нажмите "Исправить" для конкретной ошибки
4. Или "Исправить все" для массового исправления
5. Отслеживайте статус (исправлено/не исправлено)

### Логи
1. Просматривайте системные события
2. Обращайте внимание на поле "details" — там подсказки
3. Цветовая кодировка помогает быстро найти ошибки
4. Новые записи появляются автоматически
