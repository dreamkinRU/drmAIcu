## 📥 Установка

### Шаг 1: Скачай файлы

1. Открой `public/index.html` в браузере
2. Скачай все файлы:
   - `main.py` (v3.0.8)
   - `agent_engine.py` (v2.3)
   - `launcher.bat`
   - `settings.json`
   - `context_manager.py`

### Шаг 2: Замени файлы

Перемести скачанные файлы в папку `drmAIcu` (замени существующие).

### Шаг 3: Установи зависимости

```bash
pip install nicegui ollama openai aiohttp
```

### Шаг 4: Запусти Ollama

```bash
ollama serve
```

### Шаг 5: Запусти приложение

Двойной клик на `launcher.bat` или:

```bash
python main.py
```

### Шаг 6: Открой браузер

```
http://localhost:8080
```

## 🔧 Решение проблем

### Ошибка "FileNotFoundError"
Убедись, что все файлы на месте:
- `main.py`
- `agent_engine.py`
- `settings.json`

### Ошибка "ModuleNotFoundError"
Установи зависимости:
```bash
pip install nicegui ollama openai aiohttp
```

### Ollama не отвечает
Запусти Ollama:
```bash
ollama serve
```

### Порт 8080 занят
Измени порт в `main.py`:
```python
ui.run(title='drmAIcu v3.0.8 FORTRESS', port=8081, dark=True, reload=False)
```

## 📝 Использование

### Отправка задачи моделям

1. Открой вкладку **"▶ Консоль"**
2. Введи Groq API ключ (если хочешь использовать облачные модели)
3. Напиши запрос в поле "Запрос"
4. Нажми **"▶ Отправить"**
5. Смотри результат в поле "Результат"

### Обновление файлов

1. Открой вкладку **"🛡️ Обновления"**
2. Выбери файл из списка
3. Введи описание обновления
4. Вставь новый код
5. Нажми **"🛡️ Применить обновление"**

### Отладка

1. Открой вкладку **"🐞 Отладка"**
2. Нажми **"🔌 Тест Ollama"** или **"⚙️ Тест Ядра"**
3. Смотри логи в реальном времени
