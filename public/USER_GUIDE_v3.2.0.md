# drmAIcu v3.2.0 FORTRESS — Руководство пользователя

## 🎯 Обзор

drmAIcu v3.2.0 — это комплексная система управления AI-агентами с поддержкой локальных (Ollama) и облачных (Groq) моделей. Система включает универсальный AI-Guardian для безопасного обновления кода, управление агентами, мониторинг провайдеров и MD-редактор с AI-подсказками.

## 💬 Консоль

### Назначение
Отправка запросов к LLM моделям с параллельным опросом нескольких моделей и автоматическим выбором лучшего ответа арбитром.

### Режимы работы

#### 🏠 Только Ollama
- **Модели**: Qwen 2.5 Coder 1.5B, Qwen 2.5 Coder 14B
- **Преимущества**: Работает без интернета, бесплатно, приватно
- **Требования**: Установленный Ollama (`ollama serve`)

#### ☁️ Только Groq
- **Модели**: Llama 3.1 8B, Llama 3.1 70B, Mixtral 8x7B
- **Преимущества**: Быстро, мощные модели, не требует установки
- **Требования**: API ключ от https://console.groq.com

#### ⚡ Все (Ollama + Groq)
- **Модели**: 5 моделей одновременно (2 локальные + 3 облачные)
- **Преимущества**: Максимальный выбор, арбитр выбирает лучшее
- **Требования**: И Ollama, и Groq API ключ

### Использование

1. Выберите режим работы (кнопки вверху)
2. Для Ollama: проверьте URL (по умолчанию `http://localhost:11434`)
3. Для Groq: введите API ключ
4. Напишите запрос в текстовое поле
5. Нажмите "▶ Отправить"
6. Дождитесь ответов моделей
7. Арбитр автоматически выберет лучший ответ
8. Скопируйте код кнопкой "📋 Копировать код"

### Пример запроса
```
Напиши функцию сортировки массива на Python с использованием быстрой сортировки
```

## 🤖 Управление агентами

### Назначение
Включение/выключение агентов, просмотр их описаний, импорт новых агентов из магазина.

### Встроенные агенты

#### Агент №1 — Развитие системы
- **Статус**: Активен (по умолчанию)
- **Стек**: Java, Python, VBA/Excel
- **Задача**: Исправление ошибок компиляции и импорта модулей
- **Описание**: Основной агент для развития инфраструктуры drmAIcu. Специализируется на Java/Python разработке, VBA/Excel автоматизации.

#### Агент №2 — Аналитика данных
- **Статус**: Заморожен (по умолчанию)
- **Стек**: Python, Pandas, SQL
- **Задача**: На паузе
- **Описание**: Агент для анализа данных и построения отчётов. Работает с большими объёмами данных, создаёт визуализации.

#### Агент №3 — Автоматизация отчётов
- **Статус**: Заморожен (по умолчанию)
- **Стек**: Python, Excel VBA, TTS
- **Задача**: На паузе
- **Описание**: Агент для автоматизации создания отчётов и голосовых уведомлений.

### Управление агентами

1. **Включить/выключить**: нажмите кнопку "▶ Включить" или "⏸ Выключить"
2. **Просмотр описания**: читайте описание под названием агента
3. **Мониторинг прогресса**: следите за полосой прогресса
4. **Последняя активность**: отображается справа

### Магазин агентов

Нажмите кнопку "🛒 Магазин агентов" для импорта готовых агентов:

- **Агент ML — Машинное обучение**: TensorFlow, PyTorch, Scikit-learn
- **Агент Web — Веб-разработка**: React, Node.js, PostgreSQL
- **Агент DevOps — Инфраструктура**: Docker, Kubernetes, Jenkins
- **Агент Security — Безопасность**: OWASP, Metasploit, Cryptography
- **Агент Mobile — Мобильная разработка**: React Native, Flutter, Swift

**Импорт агента**:

## 🌐 Провайдеры LLM

### Назначение
Управление локальными и облачными моделями, мониторинг статуса, настройка API ключей.

### Ollama (локально)

#### Статус
Автоматическая проверка каждые 5 секунд:
- ✅ **Онлайн** — Ollama запущен и доступен
- ❌ **Оффлайн** — Ollama не запущен или недоступен

#### Кнопки управления
- **▶ Запуск**: запустить Ollama (требует установленный Ollama)
- **🔄 Перезапуск**: перезапустить Ollama
- **⏸ Остановка**: остановить Ollama

#### Мониторинг памяти
- **RAM**: используемая оперативная память (обновление каждые 5 сек)
- **VRAM**: используемая память видеокарты (обновление каждые 5 сек)

#### URL
По умолчанию: `http://localhost:11434`
Измените если Ollama запущен на другом порту или хосте.

### Облачные провайдеры

#### Groq
- **Статус**: Онлайн (по умолчанию)
- **Моделей**: 8
- **Задержка**: ~23ms
- **Описание**: Быстрые облачные модели. Бесплатный тариф доступен.
- **Сайт**: https://console.groq.com
- **Настройка**: Введите API ключ в поле "API Key"

#### HuggingFace
- **Статус**: Онлайн (по умолчанию)
- **Моделей**: 150
- **Задержка**: ~120ms
- **Описание**: Огромная библиотека моделей. Бесплатные и платные варианты.
- **Сайт**: https://huggingface.co
- **Настройка**: Введите API ключ в поле "API Key"

#### OpenRouter
- **Статус**: Онлайн (по умолчанию)
- **Моделей**: 45
- **Задержка**: ~89ms
- **Описание**: Агрегатор моделей. Доступ к GPT-4, Claude и другим.
- **Сайт**: https://openrouter.ai
- **Настройка**: Введите API ключ в поле "API Key"

#### Gemini
- **Статус**: Оффлайн (по умолчанию)
- **Описание**: Google Gemini. Требуется API ключ от Google AI Studio.
- **Сайт**: https://makersuite.google.com
- **Настройка**: Введите API ключ в поле "API Key"

#### Together
- **Статус**: Ошибка (по умолчанию)
- **Описание**: Together AI. Ошибка подключения. Проверьте API ключ.
- **Сайт**: https://api.together.xyz
- **Настройка**: Введите API ключ в поле "API Key"

### Фильтрация

Используйте кнопки фильтрации для отображения:
- **Все**: показать все провайдеры
- **Онлайн**: показать только онлайн провайдеры
- **Оффлайн**: показать только оффлайн провайдеры

### Включение/выключение

Нажмите кнопку "✅ Вкл" или "❌ Выкл" для включения/выключения провайдера.
Выключенные провайдеры не используются при отправке запросов.

## ⟨⟩ Анализ кода

### Назначение
Автоматическое обнаружение ошибок в коде с возможностью исправления через AI-Guardian.

### Классификация ошибок

#### 🔴 Критические (Critical)
- Ошибки, которые ломают функциональность
- Требуют немедленного исправления
- Пример: `asyncio.get_event_loop()` deprecated

#### 🟡 Предупреждения (Warning)
- Потенциальные проблемы
- Могут вызвать ошибки в будущем
- Пример: HuggingFace клиент без метода запроса

#### 🔵 Рекомендации (Info)
- Улучшения кода
- Не критичны, но желательны
- Пример: Дублирование импорта

### Использование

#### Исправление одной ошибки
1. Найдите ошибку в списке
2. Нажмите кнопку "🔧 Исправить"
3. AI-Guardian применит патч
4. Ошибка помечается как "ИСПРАВЛЕНО"

#### Массовое исправление
1. Нажмите кнопку "🔧 Исправить все"
2. AI-Guardian исправит все ошибки по очереди
3. Все ошибки помечаются как "ИСПРАВЛЕНО"

### Отслеживание статуса
- **Не исправлено**: красный/жёлтый/синий фон (в зависимости от серьёзности)
- **Исправлено**: зелёный фон с пометкой "ИСПРАВЛЕНО"

### Пример ошибки

```
🔴 CRITICAL | agent_engine.py:113
asyncio.get_event_loop() — deprecated

В Python 3.10+ get_event_loop() вызывает DeprecationWarning

Решение: Заменить на asyncio.get_running_loop()

Было: loop = asyncio.get_event_loop()
Стало: loop = asyncio.get_running_loop()
```

## ▤ Системные логи

### Назначение
Отслеживание системных событий с детальной информацией для устранения ошибок.

### Уровни логов

#### ℹ️ Info (синий)
- Информационные сообщения
- Успешные операции
- Пример: "ЦУ v3.2.0 FORTRESS запущена"

#### ⚠️ Warn (жёлтый)
- Предупреждения
- Потенциальные проблемы
- Пример: "OSError: [Errno 22] в py_compile.compile"

#### ✕ Error (красный)
- Ошибки
- Требуют внимания
- Пример: "drm.cls could not be loaded"

#### ✓ Success (зелёный)
- Успешное завершение
- Пример: "Агент №1 инициализирован"

### Детальная информация

Каждая запись лога содержит:
- **Время**: формат `ЧЧ:ММ:СС`
- **Уровень**: info/warn/error/success
- **Сообщение**: краткое описание события
- **Подробности**: дополнительная информация для устранения ошибок
- **Источник**: файл или модуль, сгенерировавший событие

### Пример записи лога

```
[14:32:05] ⚠ OSError: [Errno 22] в py_compile.compile
    Строка ~160. Решение: использовать tempfile.mkstemp() вместо NamedTemporaryFile
    (main.py)
```

## 🛡️ Universal AI-Guardian

### Назначение
Безопасное обновление кода с 4-уровневой валидацией и автоматическим откатом при ошибках.

### Уровни валидации

#### 1. Синтаксис
- Проверка синтаксиса Python/JSON
- Обнаружение синтаксических ошибок
- Автоматическое отклонение невалидного кода

#### 2. Структура
- Проверка обязательных элементов
- Для `agent_engine.py`: наличие `class AgentEngine`, `async def run_task`, `async def get_code_response`, `__init__`
- Обнаружение UI вызовов вне `create_ui()`

#### 3. AI-проверка
- Отправка кода AI-модели для анализа
- Проверка логичности и корректности
- Обнаружение очевидных ошибок

#### 4. Бэкап
- Создание тройного бэкапа перед применением
- Файлы: `*.bak`, `*_verified.bak`, `*_LATEST.bak`
- Автоматический откат при ошибке применения

### Поддерживаемые файлы

- `main.py`
- `agent_engine.py`
- `settings.json`
- `launcher.bat`
- `context_manager.py`

### Использование в Python-версии

1. Откройте вкладку "🛡️ Универсальные обновления"
2. Выберите файл из списка
3. Введите описание обновления
4. Вставьте новый код
5. Нажмите "🛡️ Проверить и применить"
6. AI-Guardian проверит 4 уровня
7. При успехе — применит патч
8. При ошибке — автоматический откат

## 🔧 Решение проблем

### Ollama не отвечает

```bash
# Проверьте что Ollama запущен
ollama serve

# Проверьте что модели скачаны
ollama list

# Скачайте модели если нужно
ollama pull qwen2.5-coder:1.5b
ollama pull qwen2.5-coder:14b
```

### Groq API ошибка

- Проверьте что API ключ правильный
- Проверьте что не превышен лимит (бесплатный: 30 запросов/мин)
- Получите новый ключ: https://console.groq.com/keys

### CORS ошибка для Ollama

Ollama по умолчанию поддерживает CORS. Если ошибка:

```bash
# Запустите Ollama с разрешением CORS
OLLAMA_ORIGINS=* ollama serve
```

### Порт 5173 занят

```bash
# Запустите на другом порту
npm run dev -- --port 3000
```

### Порт 8080 занят

Измените порт в `main.py`:

```python
ui.run(title='drmAIcu v3.2.0 FORTRESS', port=8081, dark=True, reload=False)
```
