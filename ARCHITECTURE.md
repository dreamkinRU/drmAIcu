# Архитектура drmAIcu

## Компоненты
- **main.py (v3.6.0)**: UI-слой на NiceGUI/FastAPI (порт 8080): REST API, аналитик проекта, логи, рестарт. Движок патчей живёт отдельно.
- **patch_engine.py (v3.6.0 HARDENED)**: Чистое ядро движка патчей (без NiceGUI): safe_path, two-phase атомарные транзакции, `TX_LOCK`, `expected_sha`, манифест, бэкапы. Его импортируют и тесты, и UI.
- **agent_engine.py (v2.3)**: Движок ИИ для обработки задач и генерации кода.
- **src/App.tsx (v3.5.0)**: React-панель управления (порт 5173), работающая через Vite Proxy.
- **launcher.bat (v2.0 Watchdog)**: Циклический лаунчер, мониторит порты 8080/5173, убивает зависшие окна и обеспечивает автоматический перезапуск.

## Поток данных
- **Задачи ИИ**: React → Vite Proxy (`/api/task`) → FastAPI → `agent_engine.py` → Ollama/Groq API.
- **Патчинг**: React → (`/api/patches/apply`) → FastAPI → `PATCH_LOCK` (замок) → проверка `MAIN_HASH` (детект устаревшего кода) → `resolve()` (чтение с диска) → Фаза 1: Валидация всех `operations` (включая `expected_sha`) → Фаза 2: Бэкап → Запись `.tmp` → `os.replace` → Проверка побайтового SHA-256 → Обновление `patch_manifest.json`.
- **Очистка**: React → (`/api/project/scan`) → FastAPI обход дерева файлов → MD5-хеширование → Эвристический анализ `get_cleanup_recommendation` → Возврат структурированного JSON с бейджами.
- **Перезапуск**: Кнопка в шапке → `/api/system/restart` → Создание `restart.flag` → Убийство процессов → `launcher.bat` видит флаг и перезапускает.
- **Логи**: `/api/logs` возвращает последние 100 записей из глобального `LOG`.
- **Документация**: `/api/md/{name}` читает/пишет MD-файлы.
- **Модели**: `/api/ollama/models` и `/api/ollama/pull` для управления моделями.
- **Статус**: `/api/status` возвращает состояние провайдеров и версию.
- **Валидация**: `validate()` проверяет `.py` через `ast.parse` и `.json` через `json.loads`.
- **Валидация TSX**: `check_ts()` вызывает локальный `typescript` (5.9.3) через `tscheck.cjs` для проверки синтаксиса до записи.
- **Песочница путей**: `safe_path()` отклоняет `../` и абсолютные пути в операциях и файловых эндпоинтах.
- **Байтовый SHA**: `sha_file()` вычисляет SHA-256 файла по байтам для детекта изменений и `expected_sha`.

## Механизмы безопасности и надёжности (3.5.2)
- **Universal AI-Guardian**: Валидация `ast.parse` для Python, `json.loads` для JSON и `typescript` для TSX перед любой записью.
- **Двухфазный атомарный коммит**: Гарантия «всё или ничего» при мультифайловых патчах. Фаза 1 валидирует все файлы до записи; Фаза 2 пишет и проверяет контрольные суммы.
- **Замок транзакций** (`PATCH_LOCK`): Одна транзакция одновременно, защита от двойного клика (B12).
- **Детект устаревшего кода** (`MAIN_HASH`): При старте ядро сохраняет хеш `main.py`. Перед применением сверяет: если код изменился на диске вне панели — отказ с ошибкой (B19).
- **Накопление операций** (кэш в `compute_ops`): Последовательные операции над одним файлом складываются корректно, а не перезаписывают друг друга (B18).
- **Дедупликация записей**: В `apply_patch` операции дедуплицируются по файлу перед фазой записи.
- **Идемпотентность `search_and_replace`**: Если замена уже применена, операция возвращает содержимое без изменений (B17).
- **1 бэкап + ротация 10**: Вместо тройного бэкапа (`_verified.bak` + `_LATEST.bak`). Имена по относительному пути с микросекундами (`src__App.tsx_<ts>.bak`) (B6, B16).
- **Автооткат**: При несовпадении контрольной суммы после записи система восстанавливает файлы из бэкапов. `written.append()` до проверки суммы гарантирует откат сбойного файла (B7).
- **Песочница путей**: `safe_path()` отклоняет `../` и абсолютные пути (B9).
- **Байтовый SHA-256**: Контрольная сумма считается по байтам, файлы сохраняются с исходным типом переносов строк (B11).
- **Ротация манифеста**: Последние 100 записей `applied` / 500 записей `history` (B14).
- **19 тестов**: `python -m pytest tests` покрывает все критические дефекты движка (B1–B19).

## Известные ограничения и долги (3.5.2)
- **CORS/host**: Закрыто в 3.5.3 — только localhost, `127.0.0.1`.
- **`expected_sha` поддерживается движком, но не генерируется в UI**: Поле можно задать вручную в операции, но панель его автоматически не передаёт.
- **Документация**: Обновлена в 3.5.2 (патчи 083–084).
- **Версия в `main.py`**: Закрыто в 3.5.3 — `/api/status` и заголовок ядра синхронизированы с документацией.
- **Декомпозиция `main.py`**: Движок патчей вынесен в `patch_engine.py` (3.5.3); `main.py` (~870 строк) — UI-слой, `App.tsx` ещё монолит.
- **CI**: Добавлен в `.github/workflows/ci.yml` (pytest + tsc + vite build).
- **Модели в `agent_engine.py`**: Часть моделей устарела (см. долги движка).
- **Транслит в `diag.bat`**: Скрипт диагностики использует транслит, читается тяжело.
- **`sync.bat`**: Содержит символы, отображаемые как артефакты кодировки в консоли.
