# Архитектура drmAIcu

## Компоненты
- **main.py (v3.5.0 MULTI-ATOMIC)**: Ядро на NiceGUI/FastAPI (порт 8080). Отвечает за API, валидацию, атомарные транзакции патчей и умный анализ проекта.
- **agent_engine.py (v2.3)**: Движок ИИ для обработки задач и генерации кода.
- **src/App.tsx (v3.5.0)**: React-панель управления (порт 5173), работающая через Vite Proxy.
- **launcher.bat (v2.0 Watchdog)**: Циклический лаунчер, мониторит порты 8080/5173, убивает зависшие окна и обеспечивает автоматический перезапуск.

## Поток данных
1. **Задачи ИИ**: React → Vite Proxy (`/api/task`) → FastAPI → `agent_engine.py` → Ollama/Groq API.
2. **Патчинг**: React → (`/api/patches/apply`) → FastAPI `resolve()` (чтение с диска) → Фаза 1: Валидация всех `operations` → Фаза 2: Бэкап → Запись `.tmp` → `os.replace` → Проверка SHA-256 → Обновление `patch_manifest.json`.
3. **Очистка**: React → (`/api/project/scan`) → FastAPI обход дерева файлов → MD5-хеширование → Эвристический анализ `get_cleanup_recommendation` → Возврат структурированного JSON с бейджами.

## Механизмы безопасности и надёжности
- **Universal AI-Guardian**: Валидация AST для Python и JSON-парсинг перед любой записью.
- **Двухфазный атомарный коммит**: Гарантия отсутствия частичных обновлений при мультифайловых патчах.
- **Тройной бэкап**: `.bak`, `_verified.bak`, `_LATEST.bak` перед каждой модификацией.
- **Контекстный unified_diff**: Защита от "уехавших" патчей за счёт поиска по содержимому, а не по номерам строк.
- **Автооткат**: При несовпадении контрольной суммы после записи система мгновенно восстанавливает исходный файл из бэкапа.
