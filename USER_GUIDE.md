# Руководство пользователя drmAIcu

## Быстрый старт
1. Запусти `launcher.bat` (он автоматически убьёт зависшие процессы и запустит ядро + UI).
2. Открой http://127.0.0.1:5173 в браузере.
3. Для теста движка патчей: `python -m pytest tests -v` (ожидаемо **19 passed**).

## Основные вкладки

### 🖥 Консоль
- Выбери провайдера (Ollama / Groq / Все).
- Напиши запрос и нажми `Ctrl+Enter` для отправки.
- Режимы: **Fast** (первый ответивший) или **Judge** (мульти-модельный выбор с судьёй).

### 🧠 Модели
- Введи имя модели (например, `qwen2.5-coder:1.5b`).
- Нажми «Скачать» для загрузки через Ollama API.
- Кнопка «Использовать» добавляет модель в консольный промпт.

### 🔄 Патчи (PATCHMASTER)
- ИИ генерирует JSON-патч. Сохрани его в папку `patch/`.
- Система автоматически обнаружит его.
- Кнопка 👁️ **Просмотр** — сухая проверка без записи на диск.
- Кнопка ✅ **Применить** — атомарная запись с бэкапом и откатом.
- **Мульти-патчи**: один JSON обновляет несколько файлов через массив `operations`.
- Кнопка ↩ **Откатить** — восстанавливает последний применённый патч из бэкапа.
- Кнопка 📦 **Архив** — перемещает патч в `patch/archive/`.
- Кнопка ⚡ **Применить все** — массовое применение ожидающих патчей.
- **CLI-аппликатор** `apply.py`: применяет патчи со свежим импортом ядра, исключая применение устаревшим кодом из памяти панели.
- **Preflight** `080.py patch/NNN.json`: проверяет, что каждый `find` встречается в файле ровно 1 раз до применения.

### 🗂 Проект (Умная очистка)
- Нажми 🧹 **Режим очистки**.
- Система проанализирует все файлы и подсветит:
  - 🔴 Красным: безопасные для удаления (пустые, кэш, старые версии `_vX`, `_fixed`, `_ru`).
  - 🟡 Жёлтым: требующие проверки (большие логи, дубликаты).
- Нажми 🗑 **Удалить X файлов** — они перемещаются в `project_archive/` с датой.
- Переключатели категорий: критичные / важные / мусор / дубликаты.
- Поиск и фильтры по категории, имени, дубликатам.
- Превью файла перед удалением (кнопка 👁).
- Пометка важных файлов звёздочкой (защита от удаления).
- Архивация файла (кнопка 📦) вместо удаления.
- Превью и действия доступны из модального окна.
- Позиция прокрутки сохраняется при обновлении списка.
- Кнопка 🔄 **Пересканировать** обновляет анализ.

### ⚙️ Система и остальные вкладки
- Кнопка 🔄 **Перезапуск** в шапке перезапускает Python и React через `restart.flag` и watchdog-лаунчер.
- **Агенты**: включение/выключение, прогресс, магазин агентов.
- **Провайдеры**: статус онлайн/оффлайн, переключение, фильтры, поле API-ключа.
- **Код**: список найденных проблем с кнопкой «Исправить».
- **Задачи**: добавление с приоритетом и категорией, отметка выполнения, удаление.
- **Логи**: просмотр логов ядра в реальном времени.
- **Документация** (вкладка «МД»): правка MD-файлов прямо из панели.
- **Панель**: сводка агентов, провайдеров, моделей и статистики патчей.
- В шапке отображаются **ОЗУ/ВидеоОЗУ**, занятые моделями.
- В шапке счётчики: агенты, провайдеры, файлы, модели, патчи, ошибки кода, задачи.
- Нижняя панель: быстрый доступ к «МД» и «Логам».
- Активная вкладка запоминается в `localStorage` и восстанавливается.
- Логи, патчи и статус Ollama обновляются автоматически по таймерам.
- Заголовок окна — «дрмАИку Панель Управления», язык русский, автоперевод отключён.
- Порт фронтенда **5173**, порт ядра **8080**. Прокси `/апи` настроен в `вайт.конфиг.жс`.
- `ланчер.бат` мониторит оба порта и перезапускает при падении.

## Формат мультифайлового патча (3.5.2)
```json
{
  "patch_id": "027",
  "type": "multi",
  "description": "Описание изменений",
  "operations": [
    {"type": "full_replace", "target_file": "file1.md", "full_file_content": "..."},
    {"type": "unified_diff", "target_file": "file2.py", "diff": "..."},
    {"type": "search_and_replace", "target_file": "file3.tsx", "find": "старый_текст", "replace": "новый_текст"},
    {"type": "create", "target_file": "new_file.tsx", "full_file_content": "..."}
  ]
}
```

## Типы операций
- **`full_replace`** — полная замена файла. Надёжна, не зависит от текущего содержимого. Идеальна для документации и крупных правок.
- **`unified_diff`** — точечные вставки/удаления по контексту. Поиск по содержимому, а не по номерам строк.
- **`search_and_replace`** — замена подстроки. Автоматически нормализует переносы строк (CRLF ↔ LF). Идемпотентна в 3.5.2.
- **`create`** — создание нового файла. Отказывается, если файл уже существует.
- **`expected_sha`** (опциональное поле) — защита от перезаписи из устаревшей вкладки.
- **`backups`** — автоматически создаётся 1 бэкап с ротацией последних 10.
- **`rollback`** — восстановление последнего патча из бэкапа.

## Безопасность и надёжность (3.5.2)
- **Идемпотентность**: повторное применение `search_and_replace` безопасно — если замена уже есть, операция возвращает содержимое без изменений.
- **Замок от двойного клика**: одновременное применение двух патчей отклоняется.
- **Детект устаревшего кода**: если `майн.пай` изменился на диске вне панели, применение патчей блокируется с понятной ошибкой.
- **`expected_sha`**: задайте хеш файла в операции, чтобы защититься от перезаписи из устаревшей вкладки браузера.
- **Накопление операций**: 20 операций над одним файлом складываются корректно, а не перезаписывают друг друга.
- **Ротация манифеста**: `патч_манифест.джесон` хранит последние 100 применённых / 500 истории.
- **1 бэкап + ротация 10**: вместо тройного бэкапа — экономия дискового пространства.
- **Двухфазный атомарный коммит**: либо все файлы, либо ничего.
- **Валидация перед записью**: `AST` для Python, `джесон.лоадс` для JSON, `ТипСкрипт` для TSX.
- **Песочница путей**: `../` и абсолютные пути в операциях отклоняются.
- **Автооткат**: при несовпадении контрольной суммы файлы восстанавливаются из бэкапов.
