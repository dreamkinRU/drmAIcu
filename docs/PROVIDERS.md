# Настройка провайдеров ИИ

## Локальные (рекомендуется для начала)
- **Ollama**: Установить с ollama.com. Запустить `ollama serve`. Модели: `qwen2.5-coder:1.5b` (быстро), `qwen2.5-coder:14b` (качественно).

## Облачные (через API-ключи в settings.json)
- **Groq**: Бесплатный тир, очень быстрый. Модели: `llama-3.1-8b-versatile`.
- **OpenRouter**: Агрегатор, есть бесплатные модели (`qwen-2.5-coder-32b-instruct:free`).
- **Gemini**: Требуется API-ключ от Google AI Studio.
