# Universal AI-Guardian

Перед любым изменением файлов ИИ проходит 4 уровня проверки:
1. **Синтаксис**: `ast.parse` для Python, `json.loads` для JSON.
2. **Структура**: Проверка наличия обязательных классов/функций в `agent_engine.py`.
3. **AI-Check**: Судья-модель анализирует код на логику и безопасность.
4. **Бэкап**: Создаётся 3 копии файла (`*.bak`, `*_verified.bak`, `*_LATEST.bak`) перед записью.

Если проверка не пройдена, изменения отклоняются, а файл восстанавливается из бэкапа.
